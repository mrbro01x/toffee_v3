### ✨ About This Repository

This repository provides **officially authorized**, freely available streaming links for all live TV channels available on [Toffee Live](https://toffeelive.com/en/live).

I am the owner of the **toffeelive.com** domain and hold the streaming rights for the channels.  
These links are currently offered **completely free** as part of a marketing initiative to help more people discover and enjoy Toffee.

The playlist is **automatically refreshed every hour** so the signed stream URLs stay valid.

### 🚀 How to Use

#### Option 1 – IPTV Players (Recommended)
Simply paste this URL into your favorite player:
https://raw.githubusercontent.com/mrbro01x/toffee_v3/main/toffee_channels.m3u


**Compatible with:**
- TiviMate
- OTT Navigator
- VLC Media Player
- IPTV Smarters
- GSE Smart IPTV
- Perfect Player
- Kodi (with PVR IPTV Simple Client)
- Most Android TV / Smart TV IPTV apps

#### Option 2 – Direct Playback
Open any individual `.m3u8` link from the playlist in VLC, MX Player, or a browser that supports HLS.
