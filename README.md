### ✨ About This Repository

This repository provides the streaming links for all live TV channels available on [Toffee Live](https://toffeelive.com/en/live).

The playlist is **automatically refreshed every hour** so the signed stream URLs stay valid.

| File | Description | Direct Link |

### 🚀 How to Use

#### Option 1 – IPTV Players (Recommended)
Simply paste this URL into your favorite player:
https://raw.githubusercontent.com/mrbro01x/toffee_v3/main/toffee_channels.m3u


**Compatible with:**
- TiviMate
- OTT Navigator
- IPTV Smarters
- GSE Smart IPTV
- Perfect Player
- Kodi (with PVR IPTV Simple Client)
- Most Android TV / Smart TV IPTV apps

#### Option 2 – Direct Playback
Open any individual `.m3u8` link from the playlist in NS Player, MX Player, or a browser that supports HLS.

### 🔄 Update Schedule

- Links are regenerated **every hour**
- Signed URLs have a limited lifetime of an hour — always use the latest version of the playlist
- The events links have lifetime of 2 hours
- No action is required on your side; just keep using the raw GitHub links above
